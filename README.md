# ICPC-Assiut-Sheets

This repository contains **solutions to ICPC Assiut University training sheets**, primarily using the C++ programming language. It serves as a personal record of problem-solving practice as well as a reference for others preparing for ICPC contests.

## About the Problems

The problems are sourced from the [Codeforces MWSD Group Contests](https://codeforces.com/group/MWSDmqGsZm/contests) and cover a variety of topics in algorithms and data structures.  

Feel free to explore the solutions and experiment with different approaches. There is no single “correct” way to solve a problem—trying new methods and learning from mistakes is encouraged.

## Contributing

Contributions are welcome! If you have a solution to a problem that is not currently included, or an improved approach, please feel free to submit a pull request. Constructive feedback and collaboration are highly appreciated.
